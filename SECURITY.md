# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through GitHub: **Security → Report a vulnerability** on this
repository. You will get an acknowledgement within a few days, and a fix or a
mitigation plan as soon as the issue is confirmed.

## Supported versions

Only the latest release receives fixes.

This tool is for **authorized** Wi-Fi audits only. Reports about misuse scenarios are out of scope.
